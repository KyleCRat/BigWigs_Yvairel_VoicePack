# BigWigs - Yvairel's Voice Pack - MID S1

A contextual voice pack for BigWigs that tells you what to do for Midnight S1 raid abilities.

## Features

- TTS voice callouts for raid boss abilities with "on me" variants
- Covers The Dreamrift, The Voidspire, and March on Quel'Danas
- Private Aura sounds registered via LibSharedMedia for use in WeakAuras
- Debug logging system to track which sounds played per pull (`/yvp`)

## Slash Commands

| Command | Description |
|---|---|
| `/yvp debug on` | Enable debug logging |
| `/yvp debug off` | Disable debug logging |
| `/yvp pulls` | List all recorded pulls |
| `/yvp pull <n>` | Show debug log for a pull |
| `/yvp pull <n> abilities` | Show abilities for a pull |
| `/yvp clear pulls` | Clear pull history |
| `/yvp clear all` | Clear everything |
| `/yvp status` | Show status |
